BioHop — приложение «ссылки в профиле»: вы собираете страницу со ссылками, изображениями, вставками и соцсетями, выбираете тему и публикуете её по адресу /b/{slug} с готовым QR-кодом. Аккаунты хранятся в хабе HOP ID (HEL.ink).

## Установка

Установка одной командой (сначала проверяет ваш компьютер, задаёт несколько вопросов и может сам установить хаб HOP ID):

```bash
curl -fsSL https://raw.githubusercontent.com/navi-crwn/BioHop/main/install.sh | bash
```

Из клона: `./install.sh` · обновление: `./update.sh` · удаление: `./uninstall.sh`. С `--yes` берутся все значения по умолчанию; `--help` показывает параметры.
