BioHop ist eine Link-in-Bio-App: Du baust eine Seite mit deinen Links, Bildern, Einbettungen und Social-Profilen, wählst ein Thema und veröffentlichst sie unter /b/{slug}, mit fertigem QR-Code. Konten liegen im HOP-ID-Hub (HEL.ink).

## Installation

Mit einem Befehl installieren (es prüft zuerst deinen Rechner, stellt ein paar Fragen und kann auch den HOP-ID-Hub für dich einrichten):

```bash
curl -fsSL https://raw.githubusercontent.com/navi-crwn/BioHop/main/install.sh | bash
```

Aus einem Klon: `./install.sh` · aktualisieren: `./update.sh` · entfernen: `./uninstall.sh`. Mit `--yes` gelten alle Standardwerte; `--help` zeigt die Optionen.
