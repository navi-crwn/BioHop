HOP · Link-in-bio

Tus enlaces, una página, publicados en segundos

BioHop convierte una sola página en tu hogar en la web: enlaces, contenido incrustado, redes sociales y un código QR en hel.ink/b/{slug}, gestionado desde bio.hel.ink. Autoalojable, de código abierto y parte de la familia HOP.

Lo que hace BioHop

  • Páginas bio públicas con QR y seguimiento de clics

    Cada página vive en hel.ink/b/{slug}, incluye su propio código QR y registra cuándo la gente hace clic en tus enlaces.

  • Un editor completo en /bio

    Gestiona páginas y enlaces, sube imágenes, avatares, iconos y logotipos para el QR, mira una vista previa en vivo, duplica páginas y consulta analíticas por página.

  • Temas predefinidos

    Temas claro, oscuro, minimalista, neón y muchos más, compartidos por el editor, su vista previa y la página pública.

  • Un inicio de sesión para todas las apps: HOP ID

    Aquí no hay registro local ni contraseñas. Inicias sesión una vez con tu HOP ID en el hub. Configura HOP_HUB_URL, HOP_APP y el secreto SSO antes de iniciar sesión.

  • Analíticas de clics

    País (GeoIP) más detección de dispositivo, navegador y bots para cada clic.

  • Acorta enlaces con LinkHop

    «Acortar esta URL» en los bloques llama a la API de LinkHop con tu propio token de servicio. Si LinkHop no está disponible, el bloque conserva su URL original.

  • Seguridad de URL y contenido

    El comando abuse:scan revisa páginas y bloques contra el domain_blacklist compartido de hop/safety, con programación horaria.

  • Purga de privacidad diaria

    El comando privacy:prune elimina a diario los datos de clics bio, para que las analíticas no se acumulen para siempre.

Preguntas frecuentes

¿Qué datos registra un clic?

Un clic registra el momento, el enlace y detalles derivados de país, dispositivo y navegador. BioHop purga a diario los datos de clics bio con privacy:prune.

¿Necesito registrarme?

No. BioHop no tiene registro local ni contraseñas: inicias sesión con tu HOP ID en el hub, una sola vez, y usas todas las apps de HOP.

¿Puedo autoalojarlo?

Sí. BioHop es código abierto bajo la licencia MIT. Consulta el README en GitHub para los requisitos y el inicio rápido; configuras tu propia URL del hub, nombre de app y secreto SSO.

¿Dónde informo de un problema?

Abre un issue en GitHub.
