HOP · Link-in-bio

Seus links, uma página, publicados em segundos

O BioHop transforma uma única página em seu lar na web: links, conteúdo incorporado, redes sociais e um código QR em hel.ink/b/{slug}, gerenciados pelo bio.hel.ink. Auto-hospedável, de código aberto e parte da família HOP.

O que o BioHop faz

  • Páginas bio públicas com QR e rastreamento de cliques

    Cada página vive em hel.ink/b/{slug}, tem seu próprio código QR e registra quando as pessoas clicam nos seus links.

  • Um editor completo em /bio

    Gerencie páginas e links, envie imagens, avatares, ícones e logotipos de QR, veja uma pré-visualização ao vivo, duplique páginas e acompanhe análises por página.

  • Temas predefinidos

    Temas claro, escuro, minimalista, neon e muitos outros, compartilhados pelo editor, pela pré-visualização e pela página pública.

  • Um login para todos os apps: HOP ID

    Aqui não há cadastro local nem senhas. Você entra uma vez com seu HOP ID no hub. Configure HOP_HUB_URL, HOP_APP e o segredo SSO antes de entrar.

  • Análises de cliques

    País (GeoIP) além de detecção de dispositivo, navegador e bots para cada clique.

  • Encurte links com o LinkHop

    “Encurtar esta URL” nos blocos chama a API do LinkHop com seu próprio token de serviço. Se o LinkHop estiver fora do ar, o bloco mantém a URL original.

  • Segurança de URL e conteúdo

    O comando abuse:scan verifica páginas e blocos contra o domain_blacklist compartilhado do hop/safety, em agendamento horário.

  • Limpeza diária de privacidade

    O comando privacy:prune exclui diariamente os dados de cliques bio, para que as análises não se acumulem para sempre.

Perguntas frequentes

Quais dados um clique registra?

Um clique registra o momento, o link e detalhes derivados de país, dispositivo e navegador. O BioHop limpa diariamente os dados de cliques bio com privacy:prune.

Preciso criar uma conta?

Não. Não há cadastro local nem senhas no BioHop: você entra com seu HOP ID no hub, uma única vez, e usa todos os apps HOP.

Posso hospedar eu mesmo?

Sim. O BioHop é de código aberto sob a licença MIT. Veja o README no GitHub para pré-requisitos e início rápido; você configura sua própria URL do hub, nome do app e segredo SSO.

Onde reporto um problema?

Abra uma issue no GitHub.
