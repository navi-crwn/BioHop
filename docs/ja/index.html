HOP · リンクインバイオ

あなたのリンクを 1 ページに、数秒で公開

BioHop は 1 ページをウェブ上のあなたの居場所にします。リンク・埋め込み・SNS・QR コードを hel.ink/b/{slug} に公開し、bio.hel.ink から管理。セルフホスト可能なオープンソースで、HOP ファミリーの一員です。

BioHop にできること

  • QR コードとクリック計測付きの公開 bio ページ

    各ページは hel.ink/b/{slug} にあり、専用の QR コードを添え、リンクがクリックされた記録を残します。

  • /bio のフルエディター

    ページやリンクを管理し、画像・アバター・アイコン・QR ロゴをアップロード。ライブプレビュー、ページ複製、ページ別アナリティクスに対応。

  • テーマプリセット

    ライト、ダーク、ミニマル、ネオンなど多数のプリセットを、エディター・プレビュー・公開ページで共有。

  • すべてのアプリで一度のサインイン：HOP ID

    ローカル登録もパスワードもありません。ハブで HOP ID によるサインインを一度行うだけ。サインイン前に HOP_HUB_URL、HOP_APP、SSO シークレットを設定してください。

  • クリックアナリティクス

    クリックごとに国（GeoIP）とデバイス・ブラウザー・ボット判定を記録。

  • LinkHop でリンクを短縮

    ブロックの「この URL を短縮」は、あなた自身のサービストークンで LinkHop の API を呼び出します。LinkHop が停止していても、ブロックは元の URL を保持します。

  • URL とコンテンツの安全性

    abuse:scan コマンドが 1 時間ごとのスケジュールで、hop/safety の共有 domain_blacklist に基づきページとブロックを検査します。

  • 毎日のプライバシー削除

    privacy:prune コマンドが毎日 bio のクリックデータを削除するため、アナリティクスは無限に蓄積しません。

よくある質問

クリックでは何が記録されますか？

クリックの日時、リンクに加え、国・デバイス・ブラウザーの判定結果が記録されます。BioHop は privacy:prune により bio のクリックデータを毎日削除します。

アカウント登録は必要ですか？

必要ありません。BioHop にローカル登録やパスワードはありません。ハブで HOP ID によるサインインを一度すれば、すべての HOP アプリを利用できます。

セルフホストできますか？

できます。BioHop は MIT ライセンスのオープンソースです。前提条件とクイックスタートは GitHub の README を参照。ハブ URL・アプリ名・SSO シークレットは各自で設定します。

問題はどこで報告しますか？

GitHub で issue を開いてください。
