01

ماذا يفعل BioHop

  • صفحات bio عامة مع رمز QR وتتبّع النقرات

    كل صفحة تعيش على hel.ink/b/{slug}، ومعها رمز QR خاص، وتسجيل لمن ينقر على روابطك.

  • محرّر كامل على /bio

    أدر الصفحات والروابط، وارفع الصور والصور الرمزية والأيقونات وشعارات QR، وشاهد معاينة حيّة، وانسخ الصفحات، واقرأ تحليلات كل صفحة.

  • سمات جاهزة

    سمات فاتحة وداكنة وبسيطة ونيون وغيرها الكثير، مشتركة بين المحرّر ومعاينته والصفحة العامة.

  • تسجيل دخول واحد لكل التطبيقات: HOP ID

    لا تسجيل محلي ولا كلمات مرور هنا. تسجّل الدخول مرة واحدة بمعرّف HOP ID في المحور. اضبط HOP_HUB_URL وHOP_APP وسر SSO قبل تسجيل الدخول.

  • تحليلات النقرات

    الدولة (GeoIP) مع كشف الجهاز والمتصفح والروبوتات لكل نقرة.

  • اختصر الروابط مع LinkHop

    خيار «اختصر هذا الرابط» في الكتل يستدعي واجهة LinkHop البرمجية برمز خدمتك الخاص. وإذا تعطّل LinkHop، يحتفظ الكتلة برابطها الأصلي.

  • أمان الروابط والمحتوى

    يفحص أمر abuse:scan الصفحات والكتل مقابل القائمة السوداء المشتركة domain_blacklist من hop/safety، وفق جدول ساعي.

  • تنظيف خصوصي يومي

    يحذف أمر privacy:prune بيانات نقرات bio كل يوم، فلا تتراكم التحليلات إلى الأبد.

الأسئلة الشائعة

ما البيانات التي تسجّلها النقرة؟

تسجّل النقرة التوقيت والرابط وتفاصيل مشتقة عن الدولة والجهاز والمتصفح. ينظّف BioHop بيانات نقرات bio يوميًا بأمر privacy:prune.

هل أحتاج إلى إنشاء حساب؟

لا. لا يوجد تسجيل محلي ولا كلمات مرور في BioHop: تسجّل الدخول بمعرّف HOP ID في المحور مرة واحدة وتستخدم كل تطبيقات HOP.

هل يمكنني استضافته بنفسي؟

نعم. BioHop مفتوح المصدر برخصة MIT. راجع README على GitHub للمتطلبات وخطوات البدء السريع؛ وتضبط أنت عنوان المحور واسم التطبيق وسر SSO.

عائلة HOP

BioHop جزء من عائلة HOP لتطبيقات مفتوحة المصدر قابلة للاستضافة الذاتية خلف hel.ink.
