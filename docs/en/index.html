HOP · Link-in-bio

Your links, one page, published in seconds

BioHop turns a single page into your home on the web: links, embeds, socials and a QR code at hel.ink/b/{slug}, managed from bio.hel.ink. Self-hostable, open source, part of the HOP family.

What BioHop does

  • Public bio pages with QR and click tracking

    Every page lives at hel.ink/b/{slug}, comes with its own QR code, and records when people click your links.

  • A full editor at /bio

    Manage pages and links, upload images, avatars, icons and QR logos, watch a live preview, duplicate pages and read per-page analytics.

  • Theme presets

    Light, dark, minimal, neon and many more presets, shared by the editor, its preview and the public page.

  • One sign-in for every app: HOP ID

    No local sign-up or passwords here. You sign in once with your HOP ID at the hub. Configure HOP_HUB_URL, HOP_APP and the SSO secret before sign-in.

  • Click analytics

    Country (GeoIP) plus device, browser and bot detection for every click.

  • Shorten links with LinkHop

    “Shorten this URL” in blocks calls LinkHop’s API with your own service token. If LinkHop is down, the block keeps its original URL.

  • URL and content safety

    The abuse:scan command checks pages and blocks against the shared domain_blacklist from hop/safety, on an hourly schedule.

  • Daily privacy pruning

    The privacy:prune command deletes bio click data every day, so analytics don’t pile up forever.

Run your own

BioHop is self-hostable. These steps are documented from the repository; they have not been executed as part of writing this page.

Prerequisites

PHP 8.3, Composer and Node 20+. The full quickstart and test commands are in the README on GitHub.

Sign-in configuration

Sign-in uses HOP ID single sign-on. Set HOP_HUB_URL, HOP_APP=biohop and the app-specific or shared SSO secret (32+ characters) in your .env before signing in.

Database

BioHop is designed to share one MySQL database with the hub and LinkHop, writing its own tables to the migrations_bio log. Run the hub’s migrations first so shared tables like users exist. Actual migration compatibility has not been verified by this documentation.

The database details above are documented design, not a tested guarantee.

FAQ

What data does a click record?

A click records timing, the link, and derived country, device and browser details. BioHop prunes bio click data daily with privacy:prune.

Do I need to register an account?

No. There is no local sign-up or password on BioHop: you sign in with your HOP ID at the hub, once, and use every HOP app.

Can I self-host it?

Yes. BioHop is open source under the MIT license. See the README on GitHub for prerequisites and the quickstart; you configure your own hub URL, app name and SSO secret.

Where do I report a problem?

Please open an issue on GitHub.
