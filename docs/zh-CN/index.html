HOP · 链接主页

你的链接，一个页面，几秒发布

BioHop 把一个页面变成你在网上的门面：链接、嵌入内容、社交账号和二维码就在 hel.ink/b/{slug}，由 bio.hel.ink 管理。可自托管、开源，属于 HOP 家族。

BioHop 能做什么

  • 公开 bio 页面，附二维码和点击跟踪

    每个页面都在 hel.ink/b/{slug}，配有专属二维码，并记录他人点击你链接的情况。

  • /bio 上的完整编辑器

    管理页面和链接，上传图片、头像、图标和二维码 logo，实时预览，复制页面，查看每页分析。

  • 主题预设

    浅色、深色、极简、霓虹等许多预设，由编辑器、预览和公开页面共用。

  • 一次登录，全家族通用：HOP ID

    这里没有本地注册或密码。你在 hub 用 HOP ID 登录一次即可。登录前需配置 HOP_HUB_URL、HOP_APP 和 SSO 密钥。

  • 点击分析

    每次点击都有国家/地区（GeoIP）以及设备、浏览器和机器人识别。

  • 用 LinkHop 缩短链接

    区块中的“缩短此网址”会使用你自己的服务令牌调用 LinkHop 的 API。若 LinkHop 不可用，区块保留原始网址。

  • 网址与内容安全

    abuse:scan 命令按小时计划，依据 hop/safety 的共享 domain_blacklist 检查页面和区块。

  • 每日隐私清理

    privacy:prune 命令每天删除 bio 点击数据，分析数据不会无限堆积。

常见问题

一次点击会记录什么数据？

一次点击会记录时间、链接，以及推导出的国家/地区、设备和浏览器信息。BioHop 每天用 privacy:prune 清理 bio 点击数据。

我需要注册账号吗？

不需要。BioHop 没有本地注册或密码：你在 hub 用 HOP ID 登录一次，即可使用所有 HOP 应用。

可以自托管吗？

可以。BioHop 基于 MIT 许可证开源。前提条件和快速开始请见 GitHub 上的 README；hub 地址、应用名和 SSO 密钥由你自己配置。

在哪里报告问题？

请在 GitHub 上提交 issue。
