HOP · Link-in-bio

Vos liens, une page, publiés en quelques secondes

BioHop transforme une seule page en votre chez-vous sur le web : liens, contenus intégrés, réseaux sociaux et un code QR sur hel.ink/b/{slug}, gérés depuis bio.hel.ink. Auto-hébergeable, open source, membre de la famille HOP.

Essayer BioHop Voir le code

Les adresses en direct de cette page mènent aux sites publics de la famille HOP.

Ce que fait BioHop

  • Pages bio publiques avec QR et suivi des clics

    Chaque page vit sur hel.ink/b/{slug}, avec son propre code QR, et enregistre les clics sur vos liens.

  • Un éditeur complet sur /bio

    Gérez pages et liens, téléversez images, avatars, icônes et logos QR, visualisez un aperçu en direct, dupliquez des pages et consultez des statistiques par page.

  • Thèmes prédéfinis

    Thèmes clair, sombre, minimal, néon et bien d’autres, partagés par l’éditeur, son aperçu et la page publique.

  • Une seule connexion pour toutes les applis : HOP ID

    Pas d’inscription locale ni de mot de passe ici. Vous vous connectez une fois avec votre HOP ID sur le hub. Configurez HOP_HUB_URL, HOP_APP et le secret SSO avant de vous connecter.

  • Statistiques de clics

    Pays (GeoIP) plus détection de l’appareil, du navigateur et des robots pour chaque clic.

  • Raccourcir les liens avec LinkHop

    « Raccourcir cette URL » dans les blocs appelle l’API de LinkHop avec votre propre jeton de service. Si LinkHop est indisponible, le bloc conserve son URL d’origine.

  • Sécurité des URL et du contenu

    La commande abuse:scan vérifie pages et blocs contre la domain_blacklist partagée de hop/safety, selon un planning horaire.

  • Purge quotidienne des données

    La commande privacy:prune supprime chaque jour les données de clics bio, pour que les statistiques ne s’accumulent pas indéfiniment.

L’héberger soi-même

BioHop peut être auto-hébergé. Ces étapes sont documentées à partir du dépôt ; elles n’ont pas été exécutées lors de la rédaction de cette page.

Prérequis

PHP 8.3, Composer et Node 20+. Les commandes complètes de démarrage rapide et de test figurent dans le README sur GitHub.

Configuration de la connexion

La connexion utilise l’authentification unique HOP ID. Définissez HOP_HUB_URL, HOP_APP=biohop et le secret SSO propre à l’appli ou partagé (32+ caractères) dans votre .env avant de vous connecter.

Base de données

BioHop est conçu pour partager une base de données MySQL avec le hub et LinkHop, en écrivant ses propres tables dans le journal migrations_bio. Exécutez d’abord les migrations du hub pour que les tables partagées comme users existent. La compatibilité réelle des migrations n’a pas été vérifiée par cette documentation.

Les détails de base de données ci-dessus sont un design documenté, pas une garantie testée.

FAQ

Quelles données un clic enregistre-t-il ?

Un clic enregistre l’horodatage, le lien, ainsi que le pays, l’appareil et le navigateur déduits. BioHop purge chaque jour les données de clics bio avec privacy:prune.

Dois-je créer un compte ?

Non. BioHop n’a pas d’inscription locale ni de mot de passe : vous vous connectez avec votre HOP ID sur le hub, une seule fois, puis vous utilisez toutes les applis HOP.

Puis-je l’héberger moi-même ?

Oui. BioHop est open source sous licence MIT. Consultez le README sur GitHub pour les prérequis et le démarrage rapide ; vous configurez vous-même l’URL du hub, le nom de l’appli et le secret SSO.

Où signaler un problème ?

Ouvrez une issue sur GitHub.
