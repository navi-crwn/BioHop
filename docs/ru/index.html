HOP · Ссылка-в-профиле

Ваши ссылки на одной странице — публикация за секунды

BioHop превращает одну страницу в ваш дом в интернете: ссылки, встроенный контент, соцсети и QR-код на hel.ink/b/{slug}, управление с bio.hel.ink. Самостоятельное размещение, открытый код, часть семейства HOP.

Что делает BioHop

  • Публичные bio-страницы с QR и учётом кликов

    Каждая страница живёт на hel.ink/b/{slug}, имеет свой QR-код и фиксирует клики по вашим ссылкам.

  • Полноценный редактор на /bio

    Управляйте страницами и ссылками, загружайте изображения, аватары, значки и логотипы для QR, смотрите живой предпросмотр, дублируйте страницы и изучайте статистику по каждой странице.

  • Готовые темы

    Светлая, тёмная, минималистичная, неоновая и многие другие темы — общие для редактора, его предпросмотра и публичной страницы.

  • Один вход для всех приложений: HOP ID

    Здесь нет локальной регистрации или паролей. Вы один раз входите с HOP ID на хабе. Перед входом настройте HOP_HUB_URL, HOP_APP и SSO-секрет.

  • Аналитика кликов

    Страна (GeoIP), а также определение устройства, браузера и ботов для каждого клика.

  • Сокращение ссылок через LinkHop

    Кнопка «Сократить эту ссылку» в блоках обращается к API LinkHop с вашим собственным сервисным токеном. Если LinkHop недоступен, блок сохраняет исходную ссылку.

  • Безопасность ссылок и контента

    Команда abuse:scan по часовому расписанию проверяет страницы и блоки по общему domain_blacklist из hop/safety.

  • Ежедневная очистка данных

    Команда privacy:prune удаляет данные о кликах по bio каждый день, поэтому аналитика не накапливается бесконечно.

Частые вопросы

Какие данные записывает клик?

Клик записывает время, ссылку, а также производные данные о стране, устройстве и браузере. BioHop ежедневно очищает данные о кликах по bio командой privacy:prune.

Нужно ли регистрировать аккаунт?

Нет. В BioHop нет локальной регистрации и паролей: вы один раз входите с HOP ID на хабе и пользуетесь всеми приложениями HOP.

Можно ли разместить у себя?

Да. BioHop — открытый код под лицензией MIT. Требования и быстрый старт — в README на GitHub; URL хаба, имя приложения и SSO-секрет вы настраиваете сами.
